##  Getting Started

###  Installation

Install Apex-Lanka using one of the following methods:

**Build from source:**

1. Clone the Apex-Lanka repository:
```sh
❯ git clone https://github.com/HimanthaThathsara/Apex-Lanka
```

2. Navigate to the project directory:
```sh
❯ cd Apex-Lanka
```
